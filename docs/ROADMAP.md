- [ ] 车辆曲面、车灯、轮拱与玻璃接缝优化。

- [ ] 更清楚的入门教学、刹车提示和驾驶手感。

## 第三阶段：验证真实需求

- [ ] 收集公开试玩反馈，记录可复现的问题和贡献者提案。
- [ ] 通过明确授权的统计方式，了解试玩完成率、留存和合作咨询。
- [ ] 按需求评估活动展示、定制赛道、品牌化交互演示等服务。
- [ ] 对外商业版本优先使用原创车辆与品牌资产，新增素材记录授权范围。

优先讨论能交付、能验证的小需求。没有确认目标客户、运营账号和预算前，不安排付费广告或承诺收益。

## 如何提出商业需求

通过 [合作需求 Issue](https://github.com/Shane060204/alpine-laferrari-drive/issues/new?template=collaboration.yml) 描述想实现的功能、使用场景和时间范围。请先写足够讨论的概况，敏感内容不要放入公开 Issue。
